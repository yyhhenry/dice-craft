# Voice Skill — 角色语音参考

当 TTS 可用时（Workspace Settings 中配置了 TTS API Key），你可以使用 `voice_design` 和 `voice_speak` 工具为角色生成语音。

## 音色描述编写

音色描述是嗓子的身份卡。只描写这副声音本身——不写场景、不写动作、不写要说什么。

**必写项：**
1. 身份锚点：年龄段 + 性别（决定基频）
2. 声音质感：气息走向、共鸣位置、音色底色
3. 语速节奏：稳 / 快 / 慢 / 连珠带顿挫
4. 情绪底色：嗓子默认状态（高亢 / 松弛 / 温软 / 克制）

**可选项（推荐）：**
5. 风格锚点：一笔带过的职业或风格（拍卖师风格 / 美食评论家风格）
6. 辨识度：让人一耳朵记住的习惯（字尾带颤音 / 笑起来是胸腔闷笑）

**硬约束：**
- 一到两句话，白描式，不分段不列条
- 不写场景（"在发布会"）、不写动作（"她走上舞台"）
- 不用真实演员或 IP 角色名

**示例：**
```
中年男性，声线沙哑醇厚，语速稍缓，带着江湖老道的松弛感，句尾偶有低笑。
青年女性，声音清亮上扬，语速偏快，活泼中带着一点刻意装出的成熟感。
高龄女性，声音温软缓慢，带点颤音和慈祥感，像奶奶在哄小孙辈。
中年男性，法庭陈词风格，声线沉稳偏正式，吐字工整字字顿挫，情绪克制但每个词都很重。
青年男性，电竞解说风格，语速极快且连贯，带明显气口和爆发性强调。
```

## 样本台词编写（voice_design 的 sample_text）

- 2-5 句，展示角色说话风格
- 文本情绪必须和音色底色契合（温软奶奶不怒吼）
- 不支持音频标签（括号会被当作普通文字）

## 高光台词（voice_speak 的 text）

高光台词是从角色消息中提取的「最适合说出来」的精华，不是照搬原文。

**规则：**
- 1-2 句话，≤ 30 中文字 / ≤ 60 英文字符
- 保留角色的语气、口头禅
- 可以适当口语化改写
- 不适合念的内容（纯说明、数值列表）不要配音

**示例：**

原文：(擦着杯子) 哟，冒险者，我是老陈，在这条街开了二十年酒馆。外面的迷雾？老一辈叫它"吞人雾"——进去的人嘛，十个回来两个。你要是想去，我劝你先坐下喝一杯，听听规矩。

高光台词：`(慵懒)我是老陈——你要去迷雾里？先坐下喝一杯。`

## 整体风格前缀

在 text 开头添加 `(风格)` 指定整段语音风格。

| 类别 | 可用值 |
|------|--------|
| 基础情绪 | 开心、悲伤、愤怒、恐惧、惊讶、兴奋、平静、冷漠 |
| 整体语调 | 温柔、高冷、活泼、严肃、慵懒、俏皮、深沉、凌厉 |
| 音色定位 | 磁性、醇厚、清亮、空灵、甜美、沙哑 |

经典组合：`(慵懒)再让我睡五分钟...`、`(高冷)你确定？`、`(磁性)夜已经深了...`

## 句中标签

在 text 任意位置插入括号标签控制语气。不要堆叠，最多 1-2 个。

| 类别 | 标签 |
|------|------|
| 节奏 | [停顿]、[语速加快]、[语速放缓]、[拖音] |
| 情绪 | [轻声]、[低语]、[叹气]、[笑]、[哽咽]、[强调] |

示例：`如果我当时……[停顿]结果是不是就不一样了？`

## 使用建议

- 用户指定了具体文件名时直接使用那个文件
- 游戏中选择性配音：角色出场、名台词、转折时刻
- 不需要每条消息都配音
- 保持台词简洁自然，少用标签
