## 二、Context Compaction

在 `AgentLoop` 中新增增量 token 估算与自动 summarize：

- `TokenEstimator`：基于消息 JSON bytes ÷ 4 估算 token，增量更新
- 估算 token 达到 `contextWindowTokens × 80%` 时自动触发 summarize
- 摘要存为 `CompactState { summary, compactedUpTo }`，模型上下文 = [summary + 最近 N 轮]
- `compact-state.json` 持久化到 session 目录，服务器重启后恢复

前端新增 `ContextUsage` 组件（进度条 + tooltip），Workspace Settings 新增 Context Window Tokens 配置项。

## 三、DND + Map 技能体系

### 目录结构

```
templates/skills/
├── dnd/
│   ├── SKILL.md           — 入口（默认 build 模式）
│   ├── builder.md         — 构建工作流：边建边展示 + self-review
│   ├── gm.md             — GM 游玩：NPC 对话、骰子、场景切换
│   ├── scripts/           — roll.py（d20）、state.py（JSON state CRUD）
│   ├── templates/         — 文件骨架
│   └── instances/         — 冒险实例（含 example_ring 完整示例）
├── map/
│   ├── SKILL.md           — 入口 + examples 表
│   ├── GUIDE.md           — CSV 格式规范、注释用法、overlay 说明
│   └── examples/          — 10 个参考地图
```

### 工作流

- **Build 模式**（默认）：创建实例文件，每个场景建完立即 `update_scene` 预览 + `message` 描述，最后 self-review
- **Play 模式**：用户明确说"开始玩"时进入，GM 叙事 + NPC 对话 + 骰子判定

### Skill 触发描述

```
- dnd: Load when user wants to create or play a DND/TRPG adventure.
- map: Load when you need to create, edit, or display a grid map.
```

旧 `dice` 和 `bluff-number-guess` skills 已移除（功能内置于 DND scripts）。

## 四、Avatar 2字显示

参考飞书规则，统一应用于聊天气泡、地图 token、角色卡：

| 类型 | 规则 | 示例 |
|------|------|------|
| 含中文 | 取后2字 | "卯香菱"→"香菱" |
| 纯英文有空格 | 取首字母 | "John Smith"→"JS" |
| 纯英文无空格 | 取前2字符 | "Henry"→"He" |

地图 token 2字时字号自动缩小以适应圆形区域。
