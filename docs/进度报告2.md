## 一、本期目标

将 DiceCraft 从纯 CLI 平台升级为 Web 应用。本期完成 **WebUI v0**（可交互的基础界面），**WebUI v1**（游玩场景画布）尚未开始。

## 二、架构变更

### 移除 CLI 入口

`src/index.ts` 不再是 REPL 循环，而是直接启动 HTTP/WebSocket 服务器。`.env` 文件配置方式已移除，模型参数改为通过 WebUI 的 Workspace Settings 界面配置，存储在 `data/workspaces/.meta/<id>-config.json`。

### 新增后端服务层 (`src/server/`)

| 文件 | 职责 |
|------|------|
| `index.ts` | Hono app 组装，REST 路由注册 |
| `start.ts` | `Bun.serve()` 入口，HTTP + WebSocket upgrade |
| `app-pool.ts` | 每 session 懒创建 App 实例，恢复历史和 NPC |
| `ws.ts` | WebSocket 连接管理、消息分发、状态广播 |
| `routes/workspaces.ts` | Workspace CRUD + config API |
| `routes/sessions.ts` | Session CRUD + messages 查询 |

### 新增前端 (`packages/dice-craft-webui/`)

React + Vite + shadcn/ui + Tailwind CSS，monorepo 结构（Bun workspaces）。

**布局**：可折叠左侧 sidebar + 可 resize 的中央画布/右侧聊天面板。

**组件**：WorkspaceSelect、SessionList（含创建/删除）、ChatPanel（消息列表 + 浮动输入框 + 状态指示器）、ScenePlaceholder。

## 三、WebSocket 实时通信

协议：
```
客户端 → 服务端: { type: "send_message", payload: { content } }
服务端 → 客户端: { type: "message", payload: ChatMessage }
服务端 → 客户端: { type: "status", payload: { primaryActive, npcCount } }
```

前端 `useWebSocket` hook 在 dev 模式通过 `import.meta.env.DEV` 直连后端 3001 端口（Vite WS proxy 与 Bun WebSocket 不兼容），生产环境走同源。

## 四、NPC 生命周期管理

本期建立了完整的 NPC 生命周期抽象，解决了此前 NPC 回复一次后就"消失"无法再交互的根本问题。

### 设计思路

NPC 被建模为**常驻后台 agent**——一旦 spawn 即持久存在于内存中，GM 可以在游戏全程中反复通过 `notify` 向同一个 NPC 发送信息并获取回复。NPC 保留完整的对话历史和角色记忆，不会因为某一轮回复结束就被回收。

当 GM 判断 NPC 不再需要时（如开启新游戏、用户明确结束当前游戏），使用 `dismiss_npc` 工具主动关闭。被关闭的 NPC 在 session 元数据中标记 `dismissed: true`，下次恢复 session 时不再重建。

### 具体变更

| 变更 | 说明 |
|------|------|
| `spawn_subagent` 移除 `background` 参数 | 按 agent_type 自动决定：NPC 总是后台持久，explore/general/review 总是前台同步返回 |
| 新增 `dismiss_npc` 工具 | GM 主动关闭指定 NPC（从内存移除 + 持久化标记） |
| `SessionInfo` 新增 `dismissed` 字段 | 恢复时过滤已关闭的 NPC，只重建活跃的 |
| Background subagent 完成后保留 loop | 修复了"回复一次后无法再 notify"的 bug |
| `SubagentDispatcher` 追踪 agentType | `getNpcCount()` 只统计 NPC 类型，前端实时显示活跃 NPC 数量 |

### 前端体现

输入框左下角通过 WebSocket status 推送实时显示当前活跃 NPC 数量（Bot 图标 + 数字），hover 显示 tooltip。GM 创建或关闭 NPC 时数字实时更新。
