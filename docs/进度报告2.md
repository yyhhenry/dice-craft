### 新增前端 (`packages/dice-craft-webui/`)

## 三、WebSocket 实时通信

协议：
```
客户端 → 服务端: { type: "send_message", payload: { content } }
服务端 → 客户端: { type: "message", payload: ChatMessage }
服务端 → 客户端: { type: "status", payload: { primaryActive, npcCount } }
服务端 → 客户端: { type: "scene.updated", payload: SceneState }
```

前端 `useWebSocket` hook 在 dev 模式通过 `import.meta.env.DEV` 直连后端 3001 端口（Vite WS proxy 与 Bun WebSocket 不兼容），生产环境走同源。

## 四、NPC 生命周期管理

本期建立了完整的 NPC 生命周期抽象，解决了此前 NPC 回复一次后就"消失"无法再交互的根本问题。

NPC 被建模为**常驻后台 agent**——一旦 spawn 即持久存在于内存中，GM 可以在游戏全程中反复通过 `notify` 向同一个 NPC 发送信息并获取回复。NPC 保留完整的对话历史和角色记忆，不会因为某一轮回复结束就被回收。GM 判断 NPC 不再需要时，使用 `dismiss_npc` 工具主动关闭。

| 变更 | 说明 |
|------|------|
| `spawn_subagent` 移除 `background` 参数 | 按 agent_type 自动决定：NPC 总是后台持久，explore/general/review 总是前台同步返回 |
| 新增 `dismiss_npc` 工具 | GM 主动关闭指定 NPC（从内存移除 + 持久化标记） |
| `SessionInfo` 新增 `dismissed` 字段 | 恢复时过滤已关闭的 NPC，只重建活跃的 |
| Background subagent 完成后保留 loop | 修复了"回复一次后无法再 notify"的 bug |
| `SubagentDispatcher` 追踪 agentType | `getNpcCount()` 只统计 NPC 类型，前端实时显示活跃 NPC 数量 |

## 五、Scene 渲染系统

本期重点工作——在中央画布区实现 2D 像素风格瓦片地图场景渲染系统，让 GM agent 能够使用预定义素材搭建可变场景。完整设计见 [PLAN-scene.md](PLAN-scene.md)。

### 后端

| 模块 | 说明 |
|------|------|
| `src/scene/manager.ts` — SceneManager | 场景状态 CRUD，CSV 地图文件解析，持久化到 `data/sessions/<id>/scene-state.json` |
| `src/tool/scene.ts` — update_scene 工具 | GM 专用，接收 SceneState 部分字段并合并；支持 `mapFile` 引用 CSV 地图文件 |
| `GET /sessions/:id/scene` | REST 端点，前端初始加载场景状态 |
| `scene.updated` WebSocket 事件 | GM 调用 update_scene 后实时广播，前端即时更新 |

**SceneState 数据模型**包含：场景标题、地图（网格 + 叠加物 + 标签）、角色列表（含位置/阵营/可见性）、主线任务、玩家角色卡。

### CSV 地图文件格式

GM 通过 CSV 文件表达地图网格，每个逗号分隔的词对应一格地形：

```csv
wall,wall,wall,wall,wall,wall
wall,wood,wood,wood,wood,wall
wall,wood,wood,wood,wood,wall
wall,wall,wall,wood,wall,wall
```

选择 CSV 而非单字符图例，因为 LLM 以 token 为单位工作——`wall`、`grass` 等英文单词通常是 1 个 token，自文档化且 edit 工具替换时不容易出错。支持点修饰符变体（如 `wood.dark`、`stone.light`）。

### 前端场景组件

| 组件 | 职责 |
|------|------|
| `PlaySurface.tsx` | 场景区总容器，组装所有子组件 |
| `MapPanel.tsx` | 地图区域容器，无网格时显示占位 |
| `TileMapSvg.tsx` | SVG 网格渲染：地形瓦片 + 叠加物 + 标签 + 角色 Token，支持滚轮缩放/拖拽平移 |
| `terrain.ts` | 10 种地形的 16×16 像素艺术瓦片，SVG `<pattern>` 程序化生成，`crispEdges` 方块像素感 |
| `CharacterBadge.tsx` | 角色信息面板，按阵营颜色区分 |
| `QuestPanel.tsx` | 主线任务面板，显示目标列表和完成状态 |
| `PlayerCardPanel.tsx` | 玩家角色卡，显示属性/资源/状态效果 |
| `ScenePlaceholder.tsx` | GM 未设置场景时的空状态提示 |
| `useScene` hook | REST 初始加载 + WebSocket `scene.updated` 实时更新 |

### 内置素材

**地形瓦片**（10 种）：void、grass、stone、wood、dirt、sand、water、wall、lava、ice，每种支持 `.dark` / `.light` 变体。

**叠加物**（5 种）：door、chest、trap、stairs、marker，程序化 SVG 图标。

**角色 Token**：按阵营着色（蓝=玩家、金=友方、绿=中立NPC、红=敌方、灰=无关），显示角色名首字母。

### 迭代优化

开发过程中经历了多轮优化：
- 地形纹理从 SVG pattern 升级为 16×16 像素艺术瓦片，视觉效果更佳
- 地图格式从文本艺术切换为 CSV，降低 LLM 编辑出错率
- 数组合并策略从按 id 合并改为全量替换，简化 GM 操作心智负担
- `SceneState` 精简：移除未使用的 `dm` 和 `texts` 字段
- 角色可见性字段从 `visible` 改为 `hidden`（默认可见更符合直觉）
- GM 未设置场景时隐藏场景 UI，避免空面板干扰
